## Descripción general

Caps My Luck es el sitio web de una tienda de gorras de alta calidad y estilo único, con entregas en Rafael Lara Grajales, Puebla.

## Tecnologías

- [Next.js 16](https://nextjs.org) (App Router)
- [React 19](https://react.dev) con el [React Compiler](https://react.dev/learn/react-compiler)
- [TypeScript](https://www.typescriptlang.org)
- [Tailwind CSS v4](https://tailwindcss.com)
- [shadcn/ui](https://ui.shadcn.com) sobre [Base UI](https://base-ui.com), con iconos de [Lucide](https://lucide.dev)
- [Oxc](https://oxc.rs) (oxlint, oxfmt), [Knip](https://knip.dev), [Lefthook](https://lefthook.dev) y [commitlint](https://commitlint.js.org)
- [pnpm](https://pnpm.io)

## Primeros pasos

### Requisitos previos

- Node.js
- pnpm 12

### 1. Instalar

```bash
git clone https://github.com/isahecam/capsmyluck-web.git
cd capsmyluck-web
pnpm install
```

### 2. Ejecutar la aplicación

```bash
pnpm dev
```

Abre [http://localhost:3000](http://localhost:3000).

### Scripts

| Comando          | Descripción                                              |
| ---------------- | -------------------------------------------------------- |
| `pnpm dev`       | Inicia el servidor de desarrollo                         |
| `pnpm build`     | Genera la compilación de producción                      |
| `pnpm start`     | Sirve la compilación de producción                       |
| `pnpm typecheck` | Genera los tipos de rutas y revisa los tipos             |
| `pnpm lint`      | Revisa el código con oxlint                              |
| `pnpm fmt`       | Da formato con oxfmt                                     |
| `pnpm knip`      | Encuentra archivos, exportaciones y dependencias sin uso |
